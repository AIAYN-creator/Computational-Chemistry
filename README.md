# Computational Chemistry

Coursework portfolio for a university course in computational chemistry. Each session is a short, self-contained study: a chemical question, the calculations used to answer it, the scripts that automate them, and a written report with the results and conclusions.

The aim is to show the whole workflow, not only the final numbers: how each calculation is set up, how the output is processed, and how the results are read against theory and experiment.

## Repository layout

```
sessions/
└── NN-topic/
    ├── README.md          # Overview: questions, figures, key results, conclusions
    ├── report/            # Written report (PDF), when there is one
    ├── figures/           # Figures, generated by plot_figures.py
    ├── plot_figures.py    # Builds every figure from the data files
    ├── run.sh             # Runs all Gaussian inputs in a folder, skipping finished jobs
    └── exN-topic/         # One folder per exercise: inputs, Bash scripts, extracted data
```

Only inputs, scripts and extracted data are tracked. Raw Gaussian outputs are left out, so every figure can be rebuilt from the repository alone.

## Tools

- **Electronic structure:** Gaussian 09
- **Automation:** Bash on Linux (job launching, output parsing with `grep`/`awk`/`sed`)
- **Figures:** Python (NumPy, Matplotlib); PGFPlots/TikZ in the reports
- **Reports:** LaTeX
